# E-Commerce

E-Commerce est une application web dynamique développée avec React et Create React App (CRA). Ce projet a pour objectif de mettre en pratique et de démontrer les compétences fondamentales de React à travers la création d'un site vitrine e-commerce, sans recourir à des bibliothèques externes pour la gestion de l'interface ou du style.

### Technologies utilisées
- **React (CRA)** : développement de l'interface et gestion des composants.
- **CSS pur** : mise en forme et personnalisation de l'interface sans framework CSS.
- **React Icons** : intégration des icônes.
